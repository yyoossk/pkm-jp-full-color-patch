つよさの 画面に なつき度を ハートで 出す（金 日本版）
==========================================================================
使うファイル：
  src/hearts.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・つよさの 画面に なつき度を 5この ハートで 出す
（くわしい説明）
  つよさの 画面の 1ページめ（ピンク）の「タイプ」の 下に「なつきど ♥♥♡♡♡」のように 5この ハートで 出します。
  つかまえた ばかりの ポケモンは 2こ、いちばん なついて いると 5こ です。

■ しくみ
--------------------------------------------------------------------------
  ・ハートの 数 ＝（なつき度 ＋ 50）÷ 51（0〜255 → 0〜5。70 → 2、255 → 5）。なつき度は wTempMonHappiness（$d020）。
  ・LoadPinkPage の さいごの「call WaitBGMap」（$14:$4f8e）を バンク$14 の 空き（$7fc8）の Hearts_Stub に
    （Hearts を farcall して から WaitBGMap）。
  ・ハートの 絵（ぬりつぶし・わく だけ の 2まい）は VRAM の バンク1 の タイル $5e・$5f に 書く
    （バンク0 の $42〜$5f は ポケモンの 絵の うごき（アニメ）に 使われるので）。画面が ついて いるので STAT を 見て 1バイトずつ。
  ・hlcoord 9, 8 に「なつきど」、hlcoord 14, 8 から ハート 5こ。その 5ますの 色の 表（VRAM バンク1 の $9800〜 と wAttrmap）の
    ビット3（バンク1 の タイル）を たてる。
  ・ページを かえても その 5ますの ビット3 は のこるので、ほかの ページで そこに 出る 文字（のうりょくの 数字 $f6〜$ff・
    濁点 $e4・$e5）を バンク1 の 同じ 番号にも 写す（空白 $7f は バンク1 も 空白）。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・銀は 金と 同じ 作り。LoadPinkPage の さいごの WaitBGMap の 場所と バンクの 空きを 確かめる。
  ・3ページ ぜんぶで、ハートの 5ますに 出る 文字を しらべて バンク1 に 写す ものを きめる。
  ・クリスタルは つよさの 画面の 作りが ちがうので、空いて いる 行と 場所を 見なおす。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・なつき度 70 → ♥♥♡♡♡、255 → ♥♥♥♥♥、0 → ♡♡♡♡♡。
  ・ページを かえても（2・3ページの わざ・のうりょくの 数字）くずれない。ほかの ポケモンに かえても 出る。もどった あとも ふつう。
