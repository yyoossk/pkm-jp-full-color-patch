むしよけの ききめが きれたとき「もう一度 つかう？」と きく（金 日本版）
==========================================================================
使うファイル：
  src/repelask.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・むしよけの ききめが きれたとき、リュックに のこりが あれば「○○を つかいますか？」と きく
（くわしい説明）
  元のゲームでは むしよけの ききめが きれると 文が 出るだけで、つづけて つかうには リュックを ひらく ひつようが ありました。
  ききめが きれたとき リュックに むしよけ（むしよけスプレー・シルバースプレー・ゴールドスプレー）が あれば、
  「○○を つかいますか？」と きいて、はい なら その場で つかうように しました。
  ・きく ものは さいごに つかった むしよけ（なければ むしよけスプレー → シルバー → ゴールド の じゅんで ある もの）。
  ・リュックに ひとつも なければ 元と 同じ。

■ しくみ
--------------------------------------------------------------------------
  ・DoRepelStep の さいごの「ld a, BANK(RepelWoreOffScript) / ld hl, RepelWoreOffScript」（$25:$6b14）の 行き先を RepelAsk_Script に。
    元の 文（$04:$7a79）を 出した あと、リュックを しらべて「○○を つかいますか？」（yesorno）→ ききめを 入れて 1こ へらす。
  ・UseRepel（$03:$787c、17バイト）を 書きなおして、さいごを RepelAsk_Set の farcall に：
    ききめを 入れる・つかった むしよけを wRepelAskLast（$def2）に おぼえる・元の UseItemText（○○を つかった・へらす）。
  ・yesorno で wScriptVar が かわるので、きいて いる むしよけは wRepelAskItem（$def3）に とっておく。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  先頭の DEF（IF !DEF(RA_HOOK) の中）を その ROM の 値に する。
  ・RA_HOOK：DoRepelStep の ld a, BANK(RepelWoreOffScript)、RA_WOREOFF_TEXT：RepelWoreOffScript の writetext の 文。
  ・RA_USEREPEL：UseRepel（「ld a, [wRepelEffect] / and a / ld hl, ○○ / jp nz, PrintText / ld a, b / ld [wRepelEffect], a / jp UseItemText」）。
  ・wRepelAskLast・wRepelAskItem：使われていない WRAM 2バイト。
  ・文の 文字コードは 日本版 金銀クリスタルで 同じ。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・ききめが きれる →「スプレーの こうかが きれた」→「むしよけスプレーを つかいますか？」→ はい →「○○は むしよけスプレーを つかった！」、
    ききめ 100・1こ へった。いいえ → なにも しない。リュックに ない → 元の 文だけ。
  ・さいごに シルバースプレーを つかって いれば シルバースプレーを きく（ききめ 200）。
  ・リュックから ふつうに つかう（ゴールドスプレー → 250・へる・おぼえる）、ききめが のこって いる ときは 元の「まだ まえに つかった…」。
