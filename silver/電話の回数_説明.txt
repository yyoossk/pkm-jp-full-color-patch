かかってくる 電話の 回数を えらべる（ふつう／すくない／なし。金 日本版）
==========================================================================
使うファイル：
  src/phonefreq.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・ポケギアの 電話の 画面で、かかってくる 電話の 回数を えらべる（ふつう／すくない／なし）
（くわしい説明）
  トレーナーからの 再戦や ポケモンじまんの 電話が 多すぎる ときの ために、ポケギアの 電話の 画面の 下に
  「でんわ・ふつう　セレクトで　かえる」を 出し、SELECT で ふつう → すくない → なし を えらべるように しました。
  ・すくない：かかってくる 回数が 4分の1。なし：かかってこない。
  ・ウツギ博士 など、話の 中で かならず かかってくる 電話は とまりません。
  ・せっていは レポートに 書かれます。

■ しくみ
--------------------------------------------------------------------------
  ・せっていは wOptions2（$d1b0）の 使われていない ビット 1・2（0 ふつう・1 すくない・2 なし）。
  ・CheckPhoneCall（$24:$4074）の 頭の「call CheckStandingOnEntrance」を PhoneFreq_Check に：
    なし → z（電話なし）、すくない → 4分の3 は z、ほかは 元の CheckStandingOnEntrance。
    （とりたてて かかる 電話は CheckSpecialPhoneCall なので かわらない）
  ・PokegearPhone_Joypad（$24:$50cf）の 頭の ld hl, hJoyPressed を PhoneFreq_Select に：SELECT なら 切りかえて 文字を かきなおす。
  ・電話の 画面を かく 所（$24:$4dc3 の call PokegearPhone_UpdateDisplayList）の あとに 11行目に 文字を かく
    （濁点は 上の 行。10行目は 空いて いる）。
  ・小さな 入口は バンク$24 の 空き（$7fb0〜）、文字を かく 所は バンク$42 $5b00。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・PF_CHECK_HOOK：CheckPhoneCall、PF_JOYPAD_HOOK：PokegearPhone_Joypad、PF_DRAW_HOOK：電話の 画面の UpdateDisplayList の call。
  ・PF_wOptions2：wOptions2（メニューせつめい の ビット 0 の ある 所）。ビット 1・2 が 使われていないか 確かめる。
  ・クリスタルは ポケギアの 作りが 少し ちがう（電話の 画面の 行の 場所を 見て PF_COORD を 合わせる）。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・電話の 画面に「でんわ・ふつう　セレクトで　かえる」。SELECT で すくない → なし → ふつう、wOptions2 が 3・5・1（ビット 0 は そのまま）。
  ・上下で 名前を えらぶ・A で かける などは 元のまま。
  ・かかってくるかの 判定は 上の しくみの とおり（ふつうの 電話は CheckPhoneCall だけを 通る）。
