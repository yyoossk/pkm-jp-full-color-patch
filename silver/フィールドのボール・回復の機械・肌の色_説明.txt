フィールドの色を ピカチュウ版フルカラーパッチ に近づける（金銀クリスタル共通）

■ 変わること
  1. フィールドに落ちている道具のボール：ピカチュウ版の道具のボールと同じ見た目（上が赤・下が白。黒い帯はない）。
  2. ウツギ研究所の机の上の ポケモンが入っているボール（3つ）：上が赤・まん中に黒い帯とボタン・下が白 の
     モンスターボールの見た目（ピカチュウ版の 研究所のボールの絵）。
     ※ ピカチュウ版も、ポケモンが入っているボール（研究所など）だけ この絵にして、道具のボールとは 見た目を分けている。
       金銀クリスタルで ポケモンが入っているボールは 研究所の3つだけ（りゅうのあなのボールは りゅうのキバ＝道具）。
  3. ポケモンセンター（と ウツギ研究所）で回復するときの 機械の上のボールが、赤と白になる。
     機械の画面の光る線も 同じ色を使っているので、オレンジから 白になる。
  4. フィールドの人の肌の色を 少し薄くする（31,19,10 → 31,24,17。ピカチュウ版と同じ色）。
     朝・昼・夜・暗い の 赤・青・緑・茶・ピンク のパレット（主人公も ふくむ）。

■ しくみ
  ボールの色（1・2 共通）
     ・元は 赤のパレット（肌色・赤・黒）だけで描いていて、下が肌色（オレンジっぽい）だった。
       白・赤・黒 の3色を持つパレットはなく、OBJ のパレット8つは ぜんぶ使われている。
     ・OBJ は 8×8 ごとに パレットを決められるので、上の2枚（タイル0・1）は 今までどおり 赤のパレット、
       下の2枚（タイル2・3）は 白・灰・黒 のパレット（PAL_OW_EMOTE。！の吹き出し などのもの）にする。
       絵は 上の2枚が 赤と黒（光る所は 肌色＝薄くした肌色）、下の2枚が 白と黒だけになるように描いた。
       そのため 赤と白の さかいめは 8ドットめ（ピカチュウ版の道具のボールは 赤が 1ドット下まである）。
     ・InitSprite で、そのものが SPRITE_POKE_BALL か 研究所のボール なら hCurSpriteOAMFlags の bit0 を立てる
       （元は bit7 しか使っていない。OAM に書くときは and $f0 で消えるので ほかに影響しない）。
     ・.addsprite の「and $f0 / or d / ld [bc], a」を call にして、bit0 が立っていて facing のタイル番号が 2・3 なら
       パレットを PAL_OW_EMOTE にする。処理は object のバンク（$01）の空きに置く（50バイト）。
  道具のボールと 研究所のボールを分ける（1・2）
     ・どちらも 同じ SPRITE_POKE_BALL。道具のボール（142か所）はそのままにして、SPRITE_POKE_BALL の絵（PokeBallSpriteGFX）を
       ピカチュウ版の道具のボールの絵にする。
     ・金銀クリスタルで使われていない SPRITE_UNUSED_GUY（$3f）の スプライトの表（OverworldSprites の 6バイト）を、
       研究所のボールの絵（新しく置く 64バイト・4枚・STILL_SPRITE・PAL_OW_RED）にして、
       ウツギ研究所の 3つのボールの object_event の スプライト（はじめの 1バイト）を $3f にする。
  3. 回復の機械：HealMachineAnim の .palettes（白・肌色・赤・黒）の 色1（肌色）を 白に。
  4. 肌：MapObjectPals（npc_sprites.pal）の 4つの時間 × 赤・青・緑・茶・ピンク の 色1。

■ ファイル
  src/fieldcolors.asm         本体（金 日本版の値が入っている）
  tools/fieldcolors_find.py   ROM ごとにちがう所を調べる道具

■ 銀・クリスタルに入れるとき
  1. python3 tools/fieldcolors_find.py ROM.gbc で DEF が出る（金・銀・クリスタルで 命令とデータの並びが同じ）。
     出た DEF を .inc にして fieldcolors.asm より前に読みこむ（または fieldcolors.asm の先頭の DEF を書きかえる）。
     ※ 道具のボールの絵は 元の絵で さがすので、このパッチを入れる前の ROM で調べる。
  2. 自分で決める所：
     ・FC_FREE（50バイト）… FC_OBJ_BANK の空き。道具は バンクのおわりの空きを 候補として出すが、
       ほかのパッチ（バグ修正など）が使っていないか map で確かめる。
     ・FC_LABGFX_BANK / FC_LABGFX（64バイト）… 研究所のボールの絵を置く空き（どのバンクでもよい）。
  3. SPRITE_POKE_BALL は $54、使われていないスプライト SPRITE_UNUSED_GUY は $3f（金銀クリスタルとも）。
     ほかのパッチで $3f を使っているときは FC_SPRITE_LAB_BALL を 使っていない番号にする。
     PAL_OW_EMOTE は 5（白・白・灰・黒。クリスタルも同じ）。
  4. 肌の色を変えたいときは FC_SKIN_R / G / B を書きかえる。
  ※ 英語版の pokesilver / pokecrystal で 探し方を試してある（日本版は アドレスがちがうので かならず道具で調べる）。

■ 確かめたこと（金 日本版、SameBoy）
  ・キキョウシティの 道具のボール：上が赤・下が白（帯なし）。ピカチュウ版の トキワのもりの 道具のボールと 同じ見た目。
  ・ウツギ研究所の机の上の3つのボール：上が赤・黒い帯とボタン・下が白。
  ・ヨシノシティのポケモンセンターで回復：機械の上のボールが 赤と白。
  ・主人公・研究所の助手・ジョーイさん などの肌が 薄い肌色。
