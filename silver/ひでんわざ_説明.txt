ひでんわざ（話しかけて使うもの）を、ポケモンが覚えていなくても使えるようにする
==========================================================================
金・銀・クリスタル（日本版・海外版）共通。使うファイルは2つ。
  src/hmfield.asm          本体（アドレスは先頭の DEF だけ）
  tools/hmfield_find.py    ROM から hmfield.asm のアドレスを調べる


■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧に入れる短い文）
  ・ひでんわざ（いあいぎり・なみのり・かいりき・うずしお・たきのぼり）を、ポケモンが覚えていなくても
    フィールドで使える（バッジがないと使えないのは今までどおり）

（くわしい説明）
  木・水・岩・うずしお・たき に話しかけて使う ひでんわざ は、手持ちのポケモンが覚えていなくても使えます。
  ・覚えているポケモンがいれば、今までどおりそのポケモンが使います。
  ・だれも覚えていなければ、手持ちのいちばん前のポケモン（タマゴはとばす）が使います。
  ・ジムバッジがないと使えないのは今までどおりです。
  ・ずつき・いわくだき は わざマシンなので、今までどおり覚えていないと使えません。
  ・そらをとぶ・フラッシュ は手持ちのメニューから使うわざなので、変わりません（覚えているポケモンが必要）。


■ 銀・クリスタルに入れるときの手順
--------------------------------------------------------------------------
1. アドレスを調べる（元の ROM、またはほかのパッチを当てた後の ROM）
     python3 tools/hmfield_find.py 銀.gbc
   次のような行が出る（CheckPartyMove の命令の並びで探している。金・銀・クリスタルで同じ処理）。
     DEF HMFIELD_CheckPartyMove      EQU $....
     DEF HMFIELD_CheckPartyMove_BANK EQU $03
     DEF HMFIELD_wCurPartyMon        EQU $....
     DEF HMFIELD_wPartySpecies       EQU $....
     DEF HMFIELD_wPartyMon1Moves     EQU $....
     DEF HMFIELD_AddNTimes           EQU $....
   続けて、空いていそうな所（0 か $ff が続く所）が出る。

2. 新しい処理（約70バイト）を置く所を決める
     DEF HMFIELD_BANK EQU $..   ; バンク
     DEF HMFIELD_ADDR EQU $....  ; アドレス
   ほかのパッチ（クリスタル追加機能キットの features.asm・fps60.asm・minis.asm・バグ修正など）が
   使っている所と重ならないようにする（.map ファイルで確かめる）。

3. 1・2 の8行を書いた .inc を作り、hmfield.asm より前に読みこむ
   （hmfield.asm の DEF は「まだ決まっていなければ」の値なので、先に決めたほうが使われる）。
   または hmfield.asm の先頭の DEF をそのまま書きかえてもよい。
     例：src/hmfield_silver.inc を作って、組み立てるときに
         rgbasm -o obj/hmfield.o -P src/hmfield_silver.inc src/hmfield.asm
         （-P は先に読みこむファイル。build.py を使うなら hmfield.asm の先頭に INCLUDE を1行足す）

4. 組み立てて確かめる
   ・ひでんわざ を覚えていない手持ちで、木・水・岩 に話しかける →「〜を つかいますか？」→ 使える
   ・手持ちの先頭がタマゴ → 2匹目が使う
   ・バッジがない → 今までどおり使えない
   ・覚えているポケモンがいる → そのポケモンが使う

■ しくみ（変える所は2か所）
--------------------------------------------------------------------------
  ・フィールドのわざの確認（TrySurfOW・TryCutOW・TryStrengthOW・TryWhirlpoolOW・TryWaterfallOW・
    TryHeadbuttOW・HasRockSmash）は、ぜんぶ バンク3 の CheckPartyMove（d = わざ）を呼んでいる。
    バッジの確認は その外でしているので、バッジはそのまま必要。
  ・CheckPartyMove の頭8バイトを「ld a, バンク / ld hl, 新しい処理 / rst $08 / ret」に書きかえる
    （元の残りは使われなくなる）。farcall（rst $08）は呼んだ先のキャリーをそのまま返す（金・銀・クリスタル同じ）。
  ・新しい処理は、元と同じに覚えているポケモンをさがし、いなければ、わざが
    いあいぎり（$0f）・なみのり（$39）・かいりき（$46）・うずしお（$fa）・たきのぼり（$7f）のときだけ
    いちばん前のタマゴでないポケモンを wCurPartyMon にする。
    わざの名前の表示（「〜は なみのりを つかった！」）や かいりき の鳴き声は wCurPartyMon のポケモンになる。
