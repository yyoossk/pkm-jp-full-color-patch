せっていの「はなしの はやさ」に「さいこう」を 足す（金 日本版）
==========================================================================
使うファイル：
  src/textspeed.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。src/clockopt_gold.asm（せっていの とけい）と いっしょに 使う 前提
  （clockopt を 入れないときは TS_COORD を 元の $c3d3 に する）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・せっていの「はなしの はやさ」に「さいこう」（文字が 待たずに 一度に 出る）を 足す
（くわしい説明）
  はなしの はやさを さいこう・はやい・ふつう・おそい の 4つから えらべるように しました。
  さいこう に すると 会話や 戦いの 文が 1文字ずつ ではなく 一度に 出ます。
  左右で 切りかえ（はしまで いくと 反対の はしへ）。

■ しくみ
--------------------------------------------------------------------------
  ・さいこう は wOptions の 文字の 待ち（下の 3ビット）を 0 に する（はやい 1・ふつう 3・おそい 5 は 元のまま）。
    PrintLetterDelay は 待ちが 0 なら 待たない。
  ・Options_TextSpeed（$39:$4c7f）の 頭を「TextSpeedNew（バンク$42 $5a00）を farcall して もどる」に する（バンク$39 に 空きが ないため）。
    文字は「さいこう」「はやい　」「ふつう　」「おそい　」（4文字に そろえて 前の 文字を 消す）。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・TS_HOOK：Options_TextSpeed、TS_COORD：はやさの 文字の 場所（clockopt で 1行 上げて いれば その 場所）。
  ・クリスタルは せっていの 作りが 同じ（Options_TextSpeed・GetTextSpeed）。バンクの 空きに 合わせて TS_BANK・TS_ADDR を 決める。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・左右で ふつう → はやい → さいこう → おそい → ふつう（はしで 反対へ）。wOptions の 下の 3ビットが 3・1・0・5。
  ・さいこう で 看板の 文が 一度に 出る（はやい では 1文字ずつ）。戦いの 文も 一度に 出て ふつうに すすむ。
