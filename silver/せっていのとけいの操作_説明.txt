せっていの「とけい」の操作を変える（金銀クリスタル共通）

■ 変わること
  ・「おわり」を なくす。せっていは B（と START）で とじる。
  ・「とけい」の行を 15行目にして「とけい　▶ひる　 せってい」と出す（今までの項目は 1行ずつ上げたまま）。
  ・とけいの行では 左右で「ひる」（あさ・ひる・よる）か「せってい」を選ぶ。
     - 「ひる」で A … カーソルが ▷ になり、左右で あさ（4:00）・ひる（10:00）・よる（18:00）に 時計を合わせる
       （曜日はそのまま。分・秒は 0）。A か B で ▶ にもどる（この B では せっていは とじない）。
     - 「せってい」で A … 曜日・時・分を合わせる画面（つづきから はじめるときに 時計が ずれていると出る、元からある画面）。
       「とけいが くるっている かも」の文は出さず、「じゅうじキーで せんたく…」から。B で とりけし。
       おわると せっていの画面に もどり、あさ・ひる・よる の表示も 新しい時間になる。
  ・カーソルの上下：いちばん下は とけい。とけいで 下 → いちばん上、いちばん上で 上 → とけい。
  ・ゲームを始める前（タイトルの「せっていを かえる」。wMapGroup = 0）は「とけい　▶ーー」だけで、左右・A は効かない。
    「せってい」も出さない。

■ しくみ（src/clockopt_gold.asm。前の版からの ちがい）
  ・項目の数：元の おわり（7）の代わりに とけい（7）。OptionsControl の .DownPressed の cp と .UpPressed の ld [hl], n を
    7 と 8 にする（前の版は 8 と 9）。とけい・おわり 2行の表示のうち「おわり」を出すのを やめる。
  ・とけいの行で 選んでいる所を WRAM 1バイト（wClockSub。金は 使われていない $de37）に覚える。
    せっていを ひらいたとき（Options_InitClock）に 0（ひる の側）にする。
  ・カーソル（Options_CursorNew）：とけいの行なら wClockSub が 0 → 5列目、1 → 10列目 に ▶。5列目も 毎回 消す。
  ・とけいの処理（Options_Clock）：
      左 → wClockSub = 0、右 → wClockSub = 1。
      A で wClockSub = 0 … 5列目を ▷ にして、ボタンを はなすまで待ってから、
        DelayFrame / JoyTextDelay の くり返しで 左右 → 時間を変えて 表示しなおす、A・B → ボタンを はなすまで待って おわる。
      A で wClockSub = 1 … RestartClock の「ld hl, wOptions」の所から farcall（はじめの「くるっているかも」の PrintText をとばす）。
        RestartClock は おわりに ExitMenu で 画面を もどす。そのあと WaitBGMap して、ボタンを はなすまで待つ
        （「さいせってい しました」を とじた A で もういちど 入らないように）。
  ・表示：「とけい」1列目、あさ・ひる・よる 6列目、「せってい」11列目（カーソルの列 10 の右）。

■ ファイル
  src/clockopt_gold.asm      本体（金 日本版のアドレスつき。前の版を 置きかえる）
  tools/clockopt_find.py     新しく使う所（RestartClock の途中・JoyTextDelay・GetJoypad・DelayFrame・WaitBGMap・hJoyDown）を ROM から調べる

■ 銀・クリスタルに入れるとき
  1. python3 tools/clockopt_find.py ROM.gbc で DEF が出る（英語版の pokesilver / pokecrystal で 探し方を試してある）。
     RestartClock は 金銀クリスタルとも 同じ並び（はじめの PrintText の次＝ +6 の所に入る）。
  2. wClockSub（1バイト）は 使われていない WRAM を 自分で決める（ほかのパッチと重ならないように）。
  3. 銀：金と同じ作り（clockopt_gold.asm のアドレスを 銀のものにする）。
     クリスタル：クリスタル追加機能キットの clockopt.asm（項目が 9つの表）を、上の「しくみ」と同じに変える：
       表を 8つ（7 = とけい）にして おわり を消す、上下の いちばん下を 7 に、カーソル・とけいの処理・表示の列を 金と同じに。
  ※ WaitBGMap・DelayFrame は 同じ並びが いくつか あるので、出た値が あっているか 確かめる（いちばん前のものを出している）。

■ 確かめたこと（金 日本版、SameBoy）
  ・とけいの行で 左右 → ▶ が「ひる」と「せってい」を いったりきたり。
  ・「ひる」で A → ▷、右 → よる、右 → あさ、B → ▶ にもどる（せっていは とじない）。
  ・「せってい」で A → 曜日・時・分の画面。B で とりけし → せっていに もどる。A で合わせる → 「さいせってい しました」→ もどる。
  ・とけいで 下 → いちばん上、上 → とけい。ウインドウで B → とじる。
  ・ゲームを始める前：「とけい　▶ーー」、右・A で 何も起きない。
