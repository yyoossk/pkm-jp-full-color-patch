わざを おもいださせて くれる 人（金 日本版）
==========================================================================
使うファイル：
  src/moverelearn.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・フスベシティの わざわすれの 家に、わざを おもいださせて くれる おばあさんを 置く
（くわしい説明）
  元のゲームでは 一度 わすれた わざや レベルを 上げて とばした わざを、あとから おぼえなおす 方法が ありませんでした。
  ハートゴールド・ソウルシルバーと 同じく、フスベシティの わざわすれの 家（わざを わすれさせて くれる 人の 家）に
  わざを おもいださせて くれる おばあさんを 置きました。
  ・ポケモンを えらぶと、いまの レベルまでに レベルで おぼえる わざの うち、いま おぼえて いない わざを 出す。
  ・えらんだ わざを おぼえる（4つ あれば わすれる わざを えらぶ）。お金・道具は いらない。何回でも。
  ・タマゴは えらべない。おもいだせる わざが なければ そう 言う。

■ しくみ
--------------------------------------------------------------------------
  ・MoveDeletersHouse_MapAttributes（$25:$5d29）の スクリプト・イベントを バンク$45 の 新しい 表に かえる
    （元の わざわすれの 人（special MoveDeletion）と 本だなも 同じ 中身で 写した。人を 1人 足した）。
  ・手もち：SelectMonFromParty（$14:$4000）。わざの 表：EvosAttacksPointers（$10:$695f）の レベルと わざ。
  ・わざの 一覧：自分で かく（MenuBox の わくに 5つずつ。上下・はしで スクロール・A で きめる・B で やめる）。
    表は wBufferMon の 場所を 使う（数・わざ…・$ff）。
  ・おぼえる：クリスタルの MoveTutor と 同じく、メニューの 画面（FadeToMenu → SCGB_MOVE_LIST）で LearnMove（$01:$67e9）→ CloseSubmenu。
    （フィールドの まま LearnMove の わすれる わざの 画面を 出すと マップの 絵が くずれるため）

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  先頭の DEF（IF !DEF(MR_ATTR) の中）を その ROM の 値に する。
  ・MR_ATTR：MoveDeletersHouse_MapAttributes。元の イベント（ワープ・本だな・わざわすれの 人）と 同じ 中身に なって いるか、
    special MoveDeletion の 番号（MR_SPECIAL_MOVEDELETION）・本だなの jumpstd の 番号を 元の バイトで 確かめる。
  ・MR_EVOSATTACKS：EvosAttacksPointers（LearnLevelMoves の ld hl, ○○）。
  ・MR_LEARNMOVE・MR_SELECTMON：LearnMove・SelectMonFromParty。MR_BANK・MR_ADDR：空き（約 800バイト）。
  ・日本版は マップの 人が 14人まで（wMapObjects の 2番から）。人を 足す マップの 人の 数を 確かめる。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・おばあさん（5, 4）に 話す → はい → ピカチュウ（Lv50）を えらぶ → でんきショック・なきごえ・しっぽをふる・でんじは・でんこうせっか・
    かげぶんしん・たたきつける… の 一覧（5つずつ、下に ▼、スクロール）。
  ・でんこうせっか → 4つ ある → はい → たいあたりを わすれる →「1 2の…ポカン！」→「でんこうせっかを おぼえた！」→ マップに もどる。
  ・ひでんわざは わすれられない（元のまま）。いいえ → あきらめますか？（キットの 学習の くりかえし）。B → 「そうかい また いつでも おいで」。
  ・わざわすれの 人・本だなは 元のまま。
