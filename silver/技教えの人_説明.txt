技教えの 人（クリスタルの コガネシティの 人と 同じ。金 日本版）
==========================================================================
使うファイル：
  src/movetutor.asm          本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  src/movetutor_compat.inc   おぼえられる ポケモンの 表（tools/movetutor_gen.py が 作る）
  tools/movetutor_gen.py     python3 tools/movetutor_gen.py pokecrystalの場所 > src/movetutor_compat.inc
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。base.gbc を INCBIN で 読む（コガネの スクリプトを 写す）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・殿堂入りの あと、水よう日・土よう日に コガネシティに 技教えの 人が 出る（クリスタルと 同じ）
（くわしい説明）
  クリスタルで 追加された 技教えの 人を 金にも 置きました。
  殿堂入りの あと コインケースを もっていれば、水よう日と 土よう日に コガネシティの ゲームコーナーの 前に 出ます。
  コイン 4000まいで かえんほうしゃ・10まんボルト・れいとうビーム の どれかを 1回 おしえて くれます（その日は もう 出ない）。
  おぼえられる ポケモンは クリスタルと 同じ です。

■ ちがう所（クリスタルと）
--------------------------------------------------------------------------
  ・手もちの 画面で「おぼえられる／おぼえられない」は 出ない（えらんだ あとで「その ポケモンには おしえられんのう」）。
  ・おしえた あと ゲームコーナーへ 歩いて 入らず、その場で 消える。
  ・文は クリスタルの 英語版の 流れを もとに した 日本語（日本版 クリスタルの 文は ここに ないため）。

■ しくみ
--------------------------------------------------------------------------
  ・コガネの 人は 14人で いっぱい（日本版は マップの 人が 14人まで）。そこで ロケット団の 見はり（8人め。ラジオとうを
    とりもどすと ずっと 消える）の 人の 表（wMapObjects の 9番）を、殿堂入りの あとは マップに 入った ときに
    技教えの 人（12, 22・POKEFAN_M・SPINRANDOM_SLOW・赤）に 書きかえる。消える フラグは EVENT_MOVETUTOR_HIDDEN（$7fd）。
  ・コガネの スクリプトと イベント（バンク$34 $4000〜$44ee）を バンク$45 の 同じ 場所に 写し、マップの 見出しの
    スクリプトの バンクを $45 に（バンク$34 に 空きが ないため）。写した 所の callback を MAPCALLBACK_OBJECTS の
    MoveTutor_Callback に（元の setflag ×2 の あと、出る 日なら 人を 書きかえて フラグを 消す、ちがえば たてる）。
  ・出る 日：殿堂入り（イベント $0044）・コインケース・GetWeekday が 水か 土・wDailyFlags2 の ビット 6（その日 おしえた。日が かわると 消える）。
  ・おしえる：SelectMonFromParty → タマゴ・表の ビット（図鑑の 番号 - 1）→ KnowsMove → メニューの 画面で LearnMove（わざを おもいださせる 人と 同じ）。
  ・special DisplayCoinCaseBalance は 日本版 金で $4e。checkcoins・takecoins は 元の スクリプトの 命令。

■ 銀に入れるとき（クリスタルは もとから ある）
--------------------------------------------------------------------------
  ・先頭の DEF（IF !DEF(MT_ATTR) の中）を 銀の 値に する。コガネの スクリプト・イベントの 場所（MT_SRC_*）、callback の 場所、
    人の 表の 何番めが 見はりか（MT_SLOT）、殿堂入りの イベントの 番号、special の 番号、wDailyFlags2 の 空き ビット。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・殿堂入り・コインケース・水よう日：ゲームコーナーの 前に 人が 出る。月よう日：出ない。
  ・話す → はい → コイン 9999まい の 表示 → はい → かえんほうしゃ／10まんボルト／れいとうビーム／やめる。
  ・かえんほうしゃ → ピカチュウ →「その ポケモンには おしえられんのう」→ また えらぶ。
  ・10まんボルト → ピカチュウ → たいあたりを わすれて おぼえた → コイン 5999まい → 「ワハハ！ さらばじゃ！」→ 消える。wDailyFlags2 の ビット 6。
