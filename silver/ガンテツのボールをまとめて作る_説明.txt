ガンテツが ぼんぐりの ボールを まとめて 作る（金 日本版）
==========================================================================
使うファイル：
  src/kurtbulk.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・ガンテツに ぼんぐりを まとめて わたせる（わたした 数だけ 次の日に ボールを くれる）
（くわしい説明）
  元は ガンテツに ぼんぐりを 1日 1こ しか わたせませんでした。
  ぼんぐりを えらぶと、その 色の ぼんぐりを リュックに ある だけ ぜんぶ わたし、
  次の日に その 数だけ ボールを くれます（たとえば あかぼんぐり 5こ → レベルボール 5こ）。
  リュックが いっぱいで 受けとれない ときは 元と 同じく あとで もう一度 はなしかけます。

■ しくみ
--------------------------------------------------------------------------
  ・SelectApricornForKurt（special。$03:$45d1）を 新しい バンクの Kurt_Select への farcall に：
    元と 同じく ぼんぐりを えらばせて（Kurt_SelectApricorn）、リュックの その ぼんぐりの 数を
    wItemQuantityChange と wKurtCount に 入れて TossItem（ぜんぶ へる）。
  ・Script_giveitem の「ld [wItemQuantityChange], a」（$25:$764f）を Kurt_GiveQty の call に（$25:$7fc0）：
    ガンテツの 家（マップ 8-4）で wKurtCount が 0 で なければ その 数を わたす。
    ガンテツの 家で もらえる どうぐは ガンテツの ボールだけ。さいしょの ルアーボールは wKurtCount が 0 なので 1こ。
  ・wKurtCount（$d7a0）：レポートに 書かれる 所の 使われていない バイト（wEventFlags $d7aa の すぐ前の 空き）。
    この パッチを 当てる 前の レポートで ぼんぐりを わたした まま だと 0 なので 1こ（元と 同じ）。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・KB_SELECT：SelectApricornForKurt（8バイト 以上。中身は ぜんぶ Kurt_Select が する）。
    KB_Kurt_SelectApricorn・KB_TossItem・wScriptVar・wCurItem・wItemQuantityChange・wNumItems も その ROM の 値に。
  ・KB_GIVEITEM：Script_giveitem の 2つめの「call GetScriptByte」の つぎの「ld [wItemQuantityChange], a」。
    KB_GIVE_FREE：同じ バンクの 空き（約 25バイト）。60fps 版の 置き場所と かさならない ように。
  ・KB_MAP_GROUP・KB_MAP_NUMBER：KURTS_HOUSE。
  ・wKurtCount：レポートに 書かれる 使われていない 1バイト（金は wEventFlags の 前の 197バイトの 空きの おわりの 方）。
    銀は 金と 同じ 所。クリスタルは 別の 空きを さがす。
  ・クリスタルの ガンテツは 作りが ちがう（GSボール・1日 たつと ボールを 作る 所）ので、ボールを わたす 所を 見て 合わせる。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・あかぼんぐり 5こ → わたすと リュックから 5こ へる（wKurtCount = 5）→ 次の日 レベルボール ×5。
