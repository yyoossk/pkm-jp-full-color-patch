ずかんの「ぶんぷ」を 時間帯で 切りかえる（金 日本版）
==========================================================================
使うファイル：
  src/nesttime.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。src/fishnest.asm（ぶんぷの釣り）と いっしょに 使える。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・ずかんの「ぶんぷ」で START を おすと あさ・ひる・よる に 出る 場所を 切りかえて 見られる
（くわしい説明）
  金の 野生の ポケモンは あさ・ひる・よる で 出る ものが ちがいますが、ぶんぷでは 区別が ありませんでした。
  すみかの 画面で START を おすと、ぜんぶ → あさ → ひる → よる → ぜんぶ と 切りかわり、
  その 時間に 草むら・どうくつで 出る 場所だけ マークします（つり・なみのりは 時間で かわらないので そのまま）。
  上の「○○の すみか」の わくの 右に「あさ」「ひる」「よる」を 出します。カントーを 見て いた ときは カントーの まま。

■ しくみ
--------------------------------------------------------------------------
  ・FindNest の 草むらの 表を 見る 所（.FindGrass の inc hl ×3 / ld a, $15。$0a:$6655）を NestTime_Grass（$0a:$7fc9）に：
    時間帯が えらんで あれば その 時間の 7つ だけ 見る（表は 朝 7・昼 7・夜 7 の じゅん）。
  ・すみかの 画面の くりかえし（.loop の call JoyTextDelay。$24:$5e02）を NestTime_Loop に：
    START なら 時間帯を すすめて、Pokedex_GetArea を はじめから やりなおす（画面を 作りなおす）。
  ・わくを かく 所（.PlaceString_MonsNest の さいごの call PlaceString。$24:$5eb6）の あとで わくを 右に 3文字 のばして 時間帯を かく。
  ・wNestTime（$def4：0 ぜんぶ・1 あさ・2 ひる・3 よる）・wNestKanto（$def5）は 使われていない WRAM。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・NT_GRASS_HOOK：FindNest .FindGrass（銀は 金と 同じ 形）。クリスタルの FindNest も 同じ 形。
  ・すみかの 画面：銀は 金と 同じ（Pokedex_GetArea）。クリスタルは 作りが ちがう（Pokedex の 中）ので、くりかえしの 所と わくを かく 所を 探して 合わせる。
  ・NT_AREA_FREE1・2：Pokedex_GetArea と 同じ バンクの 空き（36バイトと 10バイト）。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・ホーホー：あさ・ひる → マークなし、よる → マーク、ぜんぶ → マーク。ポッポ：あさ・ひる → マーク、よる → なし。
  ・わくに「あさ」「ひる」「よる」。カントー（殿堂入りの あと 右）で 切りかえても カントーの まま。
