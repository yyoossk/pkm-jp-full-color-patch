ルギア・ホウオウが 専用わざ（エアロブラスト・せいなるほのお）を 覚えられるようにする（金銀クリスタル共通）
==========================================================================
使うファイル：
  src/sigmove.asm           本体（アドレスは先頭の DEF だけ。入っている値は クリスタル日本版）
  tools/sigmove_find.py     ROM から sigmove.asm のアドレスを調べる


■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧に入れる短い文）
  ・ルギア・ホウオウが 専用わざ（エアロブラスト・せいなるほのお）を 覚えられる

（くわしい説明）
  ルギアの エアロブラスト、ホウオウの せいなるほのお は、元のゲームでは レベル1 でしか覚えません。
  野生のポケモンは「そのレベルまでに覚える わざの 最後の4つ」を持って出てくるので、
  高いレベルで出てくる ルギア・ホウオウは 専用わざを 覚えていませんでした。わざを思い出させる人も いません。
  そこで、ルギア・ホウオウが 出てくるときの レベルを 両方 40 にして（クリスタルは 両方 60、金銀は 片方が 70 でした）、
  専用わざを 覚えて出てくるようにしました。さらに、レベル60 でも 専用わざを 覚えるようにしました。
  ・ルギア・ホウオウは 両方 レベル40 で出てきて、専用わざを 覚えています。
  ・もう つかまえている ルギア・ホウオウも、レベル60 に 上がるときに 覚えられます（もう 覚えていれば 何も出ません）。


■ 金・銀に入れるときの手順
--------------------------------------------------------------------------
1. アドレスを調べる（パッチを入れる前の ROM）
     python3 tools/sigmove_find.py ROM.gbc
   ・ルギア・ホウオウの EvosAttacks（進化なし＋レベルアップで覚える わざ）を 元の並びで さがし、
     同じバンクの EvosAttacksPointers の中の その2つの ポインタの場所を DEF で出す。
   ・表の中身が sigmove.asm の表と ちがうときは 知らせる（そのときは sigmove.asm の表を その ROM に合わせて 直す。
     第2世代の 表は 金銀クリスタルで 同じはず）。
   ・ルギア・ホウオウが 出てくるときの loadwildmon の レベルの所を SIG_LUGIA_WILD_BANK・SIG_LUGIA_WILD・
     SIG_HOOH_WILD_BANK・SIG_HOOH_WILD として出す（元の レベルも出る）。1つに しぼれないときは 候補を出すので、
     元の レベル（金銀は 40 と 70）と 合っているものを えらぶ。
     ・すでに レベル40 のほう（銀の ルギア・金の ホウオウ）は 書いても書かなくてもよい（同じ 40 を書くだけ）。

2. 空きを決めて足す
       DEF SIG_FREE  EQU $....   ; SIG_BANK の空き（48バイト）
   道具は バンクの おわりの空きを 候補として出すが、ほかのパッチが使っていないか .map ファイルで確かめる。

3. 1・2 の行を書いた .inc を作り、sigmove.asm より前に読みこむ
   （sigmove.asm の DEF は「まだ決まっていなければ」の値なので、先に決めたほうが使われる）。
     例：src/sigmove_gold.inc に DEF を書き、src/sigmove_gold.asm に
           INCLUDE "src/sigmove_gold.inc"
           INCLUDE "src/sigmove.asm"
         と書いて、それを組み立てる。
   ※ SIG_BANK・SIG_PTR_LUGIA・SIG_PTR_HOOH・SIG_FREE を 全部書く（全部そろっていないと クリスタルの値が使われる）。
   ※ レベルを変える所（SIG_LUGIA_WILD など）は 書いたものだけ 変える。書かなければ 出てくるレベルは 元のまま。
     レベルを 40 以外にしたいときは DEF SIG_WILD_LEVEL EQU nn も書く。
   ※ 専用わざを もういちど覚える レベルを変えたいときは DEF SIG_LEVEL EQU nn も書く（ふつうは 60）。

4. 組み立てて確かめる
   ・ルギア・ホウオウが 両方 レベル40 で出てきて、専用わざ・しんぴのまもり・かぜおこし・じこさいせい を 覚えていること
     （金銀の 元のゲームは 片方が レベル40、もう片方が レベル70。レベル70 だと 専用わざを 覚えていなかった）
   ・専用わざを 覚えていない レベル59 の ルギア（または ホウオウ）を レベル60 に上げると「〇〇を おぼえたい……！」が出る
   ・ほかの ポケモンの わざ・進化は 変わらない


■ しくみ
--------------------------------------------------------------------------
  ・出てくるときの レベル：ルギア・ホウオウの イベントの「loadwildmon 種類, レベル / startbattle」の レベルの 1バイトを 40 にする。
  ・レベルアップで覚える わざの表（EvosAttacks）に「db 60, 専用わざ」を足す（レベル1 の 専用わざは そのまま）。
    レベル1〜59 で 出てくる・育てるときは 今までどおり。
  ・野生のポケモンの わざ（FillMoves）は「そのレベルまでの表の わざを 順に入れ、5つ目からは いちばん古いものを 押し出す」
    なので、レベル60 以上で出てくると 専用わざが 最後の4つに入る。
  ・レベルアップで 覚えるとき（LearnLevelMoves）は、もう 覚えている わざは とばすので、
    レベル1 から 覚えている ポケモンには 何も出ない。
  ・表が 2バイト ふえて 元の場所に 入らないので、ルギアと ホウオウの 表を 同じバンクの空きに 置きなおし、
    EvosAttacksPointers の ルギア（249番）・ホウオウ（250番）の 2つの ポインタを 書きかえる。
    （元の表は そのまま残るが、もう 使われない）


■ 確かめたこと（クリスタル日本版、SameBoy）
--------------------------------------------------------------------------
  ・うずまきじまの ルギア・スズのとうの ホウオウの スクリプトを そのまま動かして、両方 レベル40 で出た。
    ルギア：エアロブラスト・しんぴのまもり・かぜおこし・じこさいせい、ホウオウ：せいなるほのお・しんぴのまもり・かぜおこし・じこさいせい
  （以下は レベル60 で出したときの 確かめ）
  ・レベル60 の 野生の ルギア：じこさいせい・ハイドロポンプ・あまごい・エアロブラスト（元は かぜおこし・じこさいせい・ハイドロポンプ・あまごい）
  ・レベル60 の 野生の ホウオウ：じこさいせい・だいもんじ・にほんばれ・せいなるほのお
  ・レベル70 の ルギア：ハイドロポンプ・あまごい・エアロブラスト・スピードスター
  ・レベル40 の ホウオウ：せいなるほのお・しんぴのまもり・かぜおこし・じこさいせい（元と同じ）
  ・マスターボールで つかまえて、パソコンの「ようすを みる」で エアロブラストを 覚えていることを 確かめた
  ・エアロブラストを 覚えていない レベル59 の ルギアに ふしぎなアメ → レベル60 →「ルギアは あたらしく エアロブラストを おぼえたい……！」
