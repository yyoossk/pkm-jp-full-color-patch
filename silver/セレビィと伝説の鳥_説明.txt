殿堂入りの あとに セレビィと カントーの 伝説の 鳥に 会える（金 日本版）
==========================================================================
使うファイル：
  src/legends.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版。base.gbc を INCBIN で 読む）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。新しい バンク $46 を 使う。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・殿堂入りの あと、ウバメのもりの ほこらで セレビィ、うずまきじま・イワヤマトンネル・シロガネやまで
    フリーザー・サンダー・ファイヤーに 会える
（くわしい説明）
  金では イベントで しか 手に 入らなかった セレビィと、金銀では 会えなかった カントーの 伝説の 鳥に 会えます。
  ・セレビィ（Lv30）：ウバメのもりの ほこらを しらべると とびだして くる。
  ・フリーザー（Lv50）：うずまきじまの いちばん おく（地下2階。ルギアの へやの 入口の よこ）
  ・サンダー（Lv50）：イワヤマトンネルの 地下1階（ひだりの かべぞい）
  ・ファイヤー（Lv50）：シロガネやまの 中（2つめの へや）
  どれも 殿堂入りの あと 1回だけ。戦った あとは いなくなります（つかまえても たおしても にげても）。
  まけて 目の前が まっくらに なった ときは また います。

■ しくみ
--------------------------------------------------------------------------
  ・会ったか どうかは wLegendFlags（$d7a1。レポートに 書かれる 使われていない バイト）の ビット 0〜3
    （0 セレビィ・1 フリーザー・2 サンダー・3 ファイヤー）。殿堂入りは EVENT_BEAT_ELITE_FOUR（$0044）。
  ・ほこら：ウバメのもりの ほこらの bg_event の スクリプトの 場所（$28:$60d3）を、
    バンク$28 の おわりの 空きに 置いた「farsjump CelebiShrine」（$28:$7ffb）に かえる。
    殿堂入り前・会った あとは 元の ほこらの 文。
  ・鳥：その マップの callback（MAPCALLBACK_OBJECTS）で、殿堂入り・まだ 会って いない なら
    wMapObjects の あいて いる ばんごうに 鳥（SPRITE_MOLTRES ＝ 鳥の ポケモンの 絵。色は 青・茶・赤）を 書き、
    AddSpriteGFX・LoadUsedSpritesGFX で 絵を 読みこむ（絵の 表は callback より 前に 作られて いるため）。
    はなしかけると「ギャーーッ！」→ 鳴き声 → loadwildmon・startbattle → disappear → ビットを たてる。
    ・うずまきじま 地下2階（3-64）・イワヤマトンネル 地下1階（3-79）・シロガネやま 2（3-67）：
      MapScripts から イベントの 表の おわりまでを 新しい バンク $46 の 同じ 場所に 写し
      （$2d:$44b2〜$44fb・$2f:$6ecf〜$6f20・$2d:$45ad〜$45d1）、MapAttributes の スクリプトの バンクと
      MapScripts を callback つきの 新しい ものに（3つとも scene・callback は もとから ない）。
      写す かたまりが 小さい（どうぐの ボールと はしごだけ）ので かんたん。
    ・かたまりの 中に ほかの パッチが あって 写せない マップは、その バンクの 空きに
      MapScripts と farsjump だけ 置く 方法も ある（ためした ときは ふたごじまで できた）。
  ・鳥は 中の マップ（どうくつ・たてもの）に だけ 置ける。外の マップは グループごとに 使う 絵が
    きまって いて（OutdoorSprites）鳥の 絵を 足す 所が ない。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・銀は 金と ほぼ 同じ。マップの スクリプト・イベントの 場所と バンクの 空きを 調べなおす
    （tools/fishnest_maps.py などで MapGroupPointers → ヘッダ → MapAttributes を たどる）。
  ・写す かたまりの 中に ほかの パッチ（バグ修正・再戦 など）が ない ことを .map で 確かめる。
  ・wLegendFlags：レポートに 書かれる 使われていない 1バイト（金・銀は wEventFlags の 前の 空き。$d7a0 は ガンテツ）。
  ・クリスタル：鳥だけ でも よい。クリスタル日本版の セレビィ（GSボール）は モバイルアダプタで しか
    もらえないので、ほこらの セレビィも 入れて よい（ほこらの 元の スクリプト（GSボールの イベント）を こわさない）。
  ・日本版は マップの 人が 14人まで。鳥を 置く マップに あきが ある ことを 確かめる。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・殿堂入り前：ほこらは 元の 文、鳥は いない。
  ・殿堂入り後：ほこら → セレビィ Lv30 と 戦い、にげた あとは 元の 文だけ（ビット 0）。
    フリーザー・サンダー・ファイヤー：絵と 色が 出て、はなしかけると Lv50 と 戦う。にげた あとは いない（ビット 2 など）。
  ・うずまきじま・イワヤマトンネルは くらい どうくつ（フラッシュが いる）。フラッシュ あり で 絵と 戦いを 確かめた。
