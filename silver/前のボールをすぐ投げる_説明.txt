戦闘で、前に 使った ボールを SELECT で すぐ 投げる（金 日本版）
==========================================================================
使うファイル：
  src/quickball.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・野生の ポケモンとの 戦闘で SELECT を おすと、前に 使った ボールを すぐ 投げる
（くわしい説明）
  野生の ポケモンとの 戦闘の メニュー（たたかう・リュック・ポケモン・にげる）で SELECT を おすと、
  リュックを ひらかずに、前に 使った ボールと 同じ ボールを 投げます。
  前に 使った ボールが もう ない とき・まだ ボールを 使って いない ときは、ふつうに リュックが ひらきます。
  トレーナーとの 戦闘では なにも おきません（むしとりたいかい・サファリゾーンは メニューが ちがうので かわりません）。
  「前に 使った ボール」は 電源を 切ると わすれます。

■ しくみ
--------------------------------------------------------------------------
  ・戦闘の メニューの MenuData（$09:$4e9f。flags $81）に STATICMENU_ENABLE_SELECT（ビット1）を 足す：$83。
    _2DMenu は SELECT で キャリーを かえす。
  ・CommonBattleMenu の「call _2DMenu」（$09:$4e8a）を QB_Menu（バンク$09 の 空き $7fcf）に：キャリーなら wQuickBall = 1。
  ・BattleMenu .next の「ld a, 1 / ldh [hBGMapMode], a」（$0f:$5fe5）を QB_Next（バンク$0f の 空き $7fc8）の call に：
    wQuickBall なら QB_Decide（新しい バンク）で きめる（トレーナー → BattleMenu へ もどる、ボールが ない → BattleMenu_Pack、
    ある → むしとりたいかいの パークボールと 同じ ながれ：LoadStandardMenuHeader → wCurItem → DoItemEffect → .got_item）。
    ボールは PokeBallEffect が 1こ へらす。
  ・BattleMenu_Pack .got_item の「call .UseItem」（$0f:$6046）を QB_Used に：使った どうぐが ボールの ポケット（wNumBalls）に
    あれば wLastBall に おぼえる。
  ・wLastBall（$defa）・wQuickBall（$defb）は 使われていない WRAM。
  ・注意：farcall は a を かえさない（バンクの きりかえで こわれる）ので、QB_Decide は b で かえす。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・銀は 金と 同じ 作り。BattleMenu の ならび（日本版は 1 たたかう・2 リュック・3 ポケモン・4 にげる）と
    MenuData・CommonBattleMenu・.got_item の バイトを 確かめる。
  ・クリスタルは BattleMenu の 作りが ちがう（チュートリアル など）ので 合わせる。

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・まだ ボールを 使って いない → SELECT で リュックが ひらく。
  ・リュックから モンスターボールを 使う → おぼえる。SELECT → モンスターボールを 投げて つかまえる。ボールが 1こ へる（10 → 9）。
