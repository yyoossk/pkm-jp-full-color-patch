そだてやの おじいさんが ２ひきの なかの よさと タマゴの ようすを おしえる（金 日本版）
==========================================================================
使うファイル：
  src/daycarehint.asm   本体（アドレスは 先頭の DEF だけ。入っている値は 金 日本版）
  組み立て：ほかの src の あとに 足す（60fps 版も 同じ）。

■ README・説明に使う文言
--------------------------------------------------------------------------
（機能の一覧）
  ・そだてやの おじいさんが ２ひきの なかの よさと タマゴが できそうか おしえて くれる
（くわしい説明）
  そだてやの 中の おじいさんに はなしかけると、おばあさんにも ポケモンを あずけて いて（２ひき）
  タマゴが まだ ない ときは、ひきとるか きく 前に：
    「２ひきは とっても なかが いい ようじゃ」「なかが いい」「まあまあ なかが いい」「あまり なかが よくない」
  の どれか（タマゴが できる みこみ 31%・16%・12%・4% の ４だんかい）と、
    「タマゴが そろそろ みつかるかも しれんぞ」／「タマゴは まだまだ じゃな」
  を いいます。いっしょに あそばない ２ひきなら「タマゴは できそうに ないわい」。

■ しくみ
--------------------------------------------------------------------------
  ・DayCareMan .AskWithdrawMon の 頭の「farcall GetBreedMon1LevelGrowth」（7バイト。$05:$6d06）を
    新しい バンクの DayCareHint への farcall に。DayCareHint は 話を して から GetBreedMon1LevelGrowth を 呼ぶ
    （かえす b・d は farcall で そのまま）。
  ・なかの よさ：CheckBreedmonCompatibility（wBreedingCompatibility）。230 以上・170 以上・110 以上・それ以外。0 と 255 は できない。
  ・「そろそろ」：つぎに タマゴを しらべる まで 40ぽ いない（wStepsToEgg）。
  ・外の おじいさん（タマゴが ある ときだけ 外に いる）は かえて いない。

■ 銀・クリスタルに入れるとき
--------------------------------------------------------------------------
  ・DH_HOOK：DayCareMan .AskWithdrawMon（farcall GetBreedMon1LevelGrowth）。銀は 金と 同じ 形。
    クリスタルも 同じ 形か 確かめる。
  ・DH_GetBreedMon1LevelGrowth・DH_CheckBreedmonCompatibility・PrintText と
    wDayCareMan・wDayCareLady・wStepsToEgg・wBreedingCompatibility を その ROM の 値に。
    （金 日本版の 2ひきめは wBreedMon2 = $dc10。英語版と ならびが ちがう）

■ 確かめたこと（金 日本版、SameBoy。通常版・60fps版）
--------------------------------------------------------------------------
  ・メタモン＋ポッポ（ちがう ID）→「まあまあ」、同じ ID →「あまり」、メタモン＋メタモン →「できそうに ないわい」。
  ・wStepsToEgg 20 →「そろそろ」、144 →「まだまだ」。そのあと 元の「ひきとるかね？」に つづく。
