ポケットモンスター金 カントー＆ジョウト（「ポケットモンスター クリスタル カントー＆ジョウト」の金版）作業メモ
==========================================================================================

■ もとにするもの
  ・金銀移植キット（クリスタル版 Ver.1.0.0、パッチ後 CRC32 A844BDEB。4MB に 0 でうめた大きさで計算）
  ・金の追加機能パッチのソース（このリポジトリの gold/。金の住所に合わせた機能はここから使う）
  ・金 後期版 CRC32 4EF7F2A5（土台）・初期版 CRC32 524478D4（どちらにも同じ IPS を当てられるようにする）

■ ビルドに使う ROM（自分で用意。リポジトリには入れない）
  ・pkfc/pkfc.gbc   ピカチュウフルカラー 151匹そろう版 60fps版（CRC32 60C018DB）… キットの住所（マップの表 $FC1F2 など）で読めることを確かめた
  ・akafc/akafc.gbc 赤フルカラー 151匹そろう版 60fps版（CRC32 52621D3F）
  ・aka/ ふつうの赤（日本版）CRC32 13652705（redtexts.py・第68弾で使う）
  ・ref/ pret の pokecrystal 3c813b0・pokered c5d8f2b・pokeyellow ca1e8ba・pokegold f2cde36
  ・RGBDS 1.0.4

■ 調べてわかったこと
  ・スクリプトの命令の表：金（初期版・後期版とも）$25:$6BE4、日本版クリスタル $25:$6CB1。
    $00〜$9D は 金とクリスタルで 同じ命令（番号も 引数も 同じ）。形が ちがって 見えた 16こ（$49・$5E〜$60・$67・$68・$6B・
    $6D〜$6F・$71・$72・$74〜$76・$7B）は、クリスタルが 人の番号を 読んだあと GetScriptObject（$25:$71E1）を よぶ ことと、
    RAM の住所が ちがう だけで、することは 同じ（$49 closetext・$7B reloadmap も 同じ はたらき）。
    $9E〜：クリスタル $9F→金 $9E（swarm）、$A0→$9F（halloffame）、$A1→$A0（credits）、$A2→$A1（warpfacing）。
    クリスタルの $9E（verbosegiveitemvar）・$A3 以降は 金に ない（使っていたら 書きかえる）。
    注意：人の番号の $FE（最後に話した人）は 金でも 使える。クリスタルの GetScriptObject で 読みかえる 特別な番号
    （$FD など）を 使っている所は 金では 使えない。
  ・第1〜9弾（ソース/base の IPS）：クリスタルの バンク $75〜$7B（新しいマップ・スクリプト 約4.6万バイト）と
    $0E（トレーナーの データ 約7900バイト）が 大部分。ほかは $00・$03・$05・$13・$1A・$1C〜$1F・$22・$25 の 小さな 書きかえ。
  ・空き：金（2MB）は ほぼ $3F の 半分だけ。金の追加機能パッチ（2MB）は $4A〜$5F・$6E〜$78・$7C〜$7F などが 空き。
    クリスタル版は 4MB（MBC30）で $9E まで 使っているので、金も 4MB にする（README 4-7・第67弾の 直しも 入れる）。

■ すすみぐあい
  ・道具（SameBoy ハーネス・RGBDS 1.0.4）・くらべる用のクリスタル完成 ROM・金の追加機能パッチのビルド（4つとも CRC 一致）まで。
  ・命令の対応表まで できた。
  ・道具（tools/）：
      consts.py   pret の定数（イベントフラグ・人の絵・曲・トレーナー・特別処理・std）を名前で読む。xlat() でクリスタル→金。
      maps.py / cmaps.py  マップの表（クリスタル $25:$4000、金 $25:$40ED）を名前つきで読む。
      cwalk.py    クリスタル（改造後）のマップから スクリプト・セリフ・移動データ・トレーナーを たどって集める。
      changed.py  元のクリスタルと くらべて 中身が変わったマップをさがす。
      mkjpsym.py  英語版 pokecrystal.sym → 日本版クリスタルの住所（crystal_jp.sym、12153こ）。金は goldsrc/src/jp_all.inc を使う。
  ・第9弾までで変わったマップ：66こ（カントーの道路・ジム・四天王・マサラ・オーキド研究所・クチバ/アサギのみなと など。
    ジョウトもいくつか）。cwalk の まだの所：Route44・SilverCaveRoom3・Route45・FuchsiaCity・BattleTowerHallway で
    範囲外エラー、Route1/2/8/11・LancesRoom・RedsHouse1F で 不明な命令（人の種類 3・4 や asm を スクリプトと読んでいる）。
  ・金で 使えない もの：special 57こ（BattleTower・Celebi・Buena など）、std 6こ（GiftM/F など）、曲 10こ（MUSIC_CLAIR など）、
    人の絵 7こ（SPRITE_KRIS・SUICUNE など）。使っていたら 移植するか 書きかえる。
  ・第1〜9弾の 試作（tools/gold_p9.py → out/gold_p9.gbc）：
      - 金を 4MB（$0148=$07）にし、CallCallback の or $80 → or $00、ExitScriptSubroutine の and $7F → and $FF（第67弾と同じ）。
      - 変わった 45 マップ（BattleTowerHallway は 金にないので とばす）を クリスタルのバンクごとに 金の $80〜$8E へ。
        ID は 名前で 読みかえ。名前のない（MOD で使い始めた）イベントフラグ $105〜$1BE・$341〜$34C は 金でも 空いているので 同じ番号。
      - スポーン0 → レッドの家2F（金 05:$5286）、シーンの表 → 主人公の家1F の 変数を レッドの家1F で（金 $9404C+12）。
      - 秘伝わざのバッジ（金 バンク03 の 8か所）、名前の候補 ゴールド→サトシ（金 $629D）。
      - 新しいゲームで レッドの家2F から 始まり、1F の お母さんの セリフまで クリスタル第9弾と 同じ に なることを 確かめた。
  ・わかった 住所：金 wStringBuffer1=$CF87（クリスタル $D071）、金 ObjectEvent=$27BF（クリスタル $26B2）。
  ・トレーナー：日本版の 種類の番号は 英語版と 同じ（1〜67。金は 66 まで）。手持ちの表 クリスタル 0E:$59BA、金 0E:$595C。
    金の 各リストは クリスタルの リストの 前の部分と 同じ 名前（クリスタルは うしろに 足している）。
    MOD は カントーの トレーナーを 書きかえ・うしろに 足している → trainers.py の merged() で 金の手持ちを 作る（8457 バイト）。
    金の バンク $0E は いっぱい（$7FC6 まで）なので、クリスタル版 第13弾と 同じく 読むコードごと 別のバンクへ 移す 必要がある。
  ・トレーナー：読むコード 0E:$5511-$595B を 新しいバンク（今は $94）の 同じ住所へ うつし、$595C に 表と merged() の 手持ち。
    farcall 12か所（21 xx xx 3E 0E CF）と RandomPhoneMon（0A）の ld a,$0E 6か所を 新しいバンクに。
  ・カントーの マップは MOD が変えていなくても クリスタル版から 入れる（地名が カントーのもの。Route26/27・トージョウのたき などは 金のまま）。
    クリスタルにしかない しくみを使うもの（タマムシ・ハナダ・ヤマブキのポケセン1F、ものまねむすめの家2F、チャンピオンロード）は 金のまま。
    → 151 マップ。マップの見出しの タイルセット（番号が ちがう）・地名・曲も 名前で 読みかえ。
  ・つながりの RAM：クリスタル wOverworldMapBlocks=$C800、金=$C700 → 書きこみ先と 窓を -$100。
  ・確かめた：レッドの家2F→1F（お母さん）→ マサラタウン → 1ばんどうろ の 画面が クリスタル第9弾と 同じ（地名の看板は 第64弾で 入れる）。
  ・確かめた（2）：マサラタウン → オーキド研究所 → オーキドの セリフ（「ほっほ！ モンスターボールの なかに…」）まで クリスタル第9弾と 同じ。
    第9弾の クリスタルも 金も「ならした もの！」で 先へ進まない（第9弾の時点の クリスタル版の うごき。のちのフェーズで 変わる）。
  ・絵：人の絵（例：マサラの せんせい）と 研究所の 入口マットは 金と クリスタルで 絵が ちがう。金に あるものは 金の絵を 使う（4-2）。
  ・まだ：トレーナー戦、ほかの マップを 歩いて 確かめる、名前の候補の 画面。
  ・つぎの 方針：第9弾の ROM では 話が 進まない所が あるので、マップと セリフは 完成版（A844BDEB）から 入れ、
    フェーズごとの プログラムの 変更（第10〜94弾）を 金に 入れていく。cwalk の callasm・text_asm の 一覧が その目安。
  ・考え：マップと セリフは 道具で まとめて うつせるので、のちの フェーズでも 同じ道具で その時点の クリスタルの ROM から 入れなおせる。
    フェーズごとに 手で うつすのは、プログラム（asm）の 書きかえ だけに なる。
