「ポケットモンスター 銀 カントー＆ジョウト」作業メモ
====================================================

クリスタル版「ポケットモンスター クリスタル カントー＆ジョウト」Ver.1.0.0（パッチ後 CRC32 A844BDEB）の中身を
ポケットモンスター銀に移植する。もとは「金銀移植キット」（README.txt・フェーズ一覧.txt・確認キット）。
このプロジェクトでは、新たにキット（ほかのバージョン用のファイルと文言）を作成しない。


■ 決めたこと
  ・新しいパッチとして作る（銀 追加機能パッチとは別）。名前は「ポケットモンスター 銀 カントー＆ジョウト」。
  ・もとにする ROM は後期版（0AEA5383）。IPS は初期版（BE1B928A）・後期版のどちらに当てても同じ ROM になる
    （build.py が 2つに当てて確かめる。ヘッダーと のばした所も入る）。
  ・機能は ../silver（銀 追加機能パッチ Ver.1.5.1）のソースを使い、60fps を入れる（クリスタル版の第64弾にあたる）。
    buildlist_mod.txt は ../silver/buildlist.txt から、クリスタル版で入れていないものを外したもの：
      safari/safari_silver.asm（サファリは この MOD のカントー＝赤のもの。第28弾・第65弾で入れる）
      legends_silver.asm（伝説の鳥は入れない。セレビィは第61・63弾で入れる）
      starters_silver.asm（カントーの御三家は第58弾のピカチュウ版の渡しかた）
      wild_silver.asm（殿堂入り前のポケモンは入れない）
    ※ rematch_silver.asm は、カントーのジムリーダーの再戦の手持ち（キットのもの）を外す必要がある（第50弾で直す）。
    ※ クリスタル版の kitfx の buildlist にない kurtbulk・movetutor・monmenu_fix・dexarea は、
      クリスタルに元からあるか features に入っているものなので、銀ではそのまま入れておく（中身を第64弾で照らし合わせる）。
  ・地名の看板：ユーザーが用意した「場所の札_銀用キット」の src/mapsign.asm・mapsign_silver.asm で上書き
    （銀 追加機能パッチ Ver.1.5.0 の札 ＋ 金で直した「消えるとき1フレーム白い」の直し）。
    MS_IDLE（サファリの表示）は第65弾で この MOD のサファリに合わせて入れる。


■ 組み立て
  roms/gin0.gbc・roms/gin1.gbc を置いて、rgbds 1.0.4 を PATH か RGBDS に。
    python3 build.py
  今の できあがり：2MB、CRC32 EE7258BD（機能・60fps・看板だけ。カントー＆ジョウトの中身はまだ）


■ 移植のしかた（調べたこと）
  ・日本版クリスタルと日本版銀では、スクリプトの命令の番号がちがう
    （英語版の pokecrystal と pokegold でも farjumptext から1つずれる。getname・wait・checksave など
     クリスタルにしかない命令もある）。ROM の命令の表：クリスタル $25:$6CB1 ごろ（164個）、銀 $25:$6BE4 ごろ（163個）。
    → クリスタル版のマップ・スクリプトは、そのまま写せない。番号を読みかえる道具（tools/）を作る。
    ROM の表の命令の処理を くらべた結果（日本版どうし）：
      命令 $00〜$9D は クリスタルと銀で 同じ番号・同じ処理。
      クリスタルの $9E（verbosegiveitemvar に あたる）は 銀に ない。
      クリスタルの $9F〜$A2 ＝ 銀の $9E〜$A1（ずれるのは ここだけ。$9F は 引数の数が ちがうので 中身も 見る）。
      クリスタルの $A3 は 第1〜9弾で 足された命令（farcall $47:$4000）。銀では 同じものを 足す。
  ・読みかえるもの：スクリプトの命令、special の番号、イベントフラグ、マップの番号（グループ・番号）、人の絵の番号、
    曲・効果音の番号、どうぐ、ランドマーク、タイルセット、テキストの命令、動きの命令。
  ・クリスタル版の完成 ROM（日本版クリスタル＋クリスタル完成パッチ）にカントーのマップ・絵・色・セリフは全部入っている。
    取り出せるものは そこから取り出す（キットの README 2）。
  ・クリスタル完成パッチは 2,588,786 バイトまでしか書かない。4MB にのばして残りを 0 でうめると A844BDEB になる。
